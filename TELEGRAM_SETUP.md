# Инструкция по настройке отправки сообщений в Telegram

## Проблема
Telegram Bot API блокирует прямые запросы из браузера из-за политики CORS. Поэтому нужен прокси-сервер.

## Решение

### Вариант 1: PHP прокси (рекомендуется для большинства хостингов)

1. **Файл `telegram-proxy.php` уже создан** в папке `public/`
2. После сборки (`npm run build`) файл будет скопирован в папку `build/`
3. Загрузите содержимое папки `build/` на ваш хостинг
4. Убедитесь, что на хостинге включен PHP
5. Файл `telegram-proxy.php` должен быть доступен по адресу: `https://ваш-сайт.ru/telegram-proxy.php`

**Проверка:**
- Откройте в браузере: `https://ваш-сайт.ru/telegram-proxy.php`
- Должна быть ошибка "Method not allowed" (это нормально, файл работает)

### Вариант 2: Node.js прокси (если есть возможность запустить Node.js сервер)

1. Установите зависимости:
```bash
npm install express cors
```

2. Запустите прокси-сервер:
```bash
node telegram-proxy.js
```

3. Обновите `src/components/ContactForm/index.jsx`:
```javascript
const PROXY_URL = "http://ваш-домен:3001/api/telegram/send";
```

4. Для production используйте PM2:
```bash
npm install -g pm2
pm2 start telegram-proxy.js --name telegram-proxy
pm2 save
pm2 startup
```

### Вариант 3: Использование сервисов (Zapier, Make.com, и т.д.)

Можно настроить webhook через сервисы автоматизации, но это требует дополнительной настройки.

## Текущая конфигурация

В файле `src/components/ContactForm/index.jsx`:
- `USE_PROXY = true` - включено использование прокси
- `PROXY_URL = "/telegram-proxy.php"` - путь к PHP прокси

## Проверка работы

1. Откройте сайт в браузере
2. Заполните форму обратной связи
3. Отправьте сообщение
4. Проверьте консоль браузера (F12) на наличие ошибок
5. Если есть ошибки CORS - убедитесь, что прокси настроен правильно

## Безопасность

✅ **Токен вынесен в переменные окружения!**

### Настройка переменных окружения

1. **Для разработки (React):**
   - Создайте файл `.env` в корне проекта (уже создан)
   - Укажите токен и chat_id:
     ```
     REACT_APP_TELEGRAM_BOT_TOKEN=your_bot_token_here
     REACT_APP_TELEGRAM_CHAT_ID=your_chat_id_here
     ```
   - Перезапустите dev-сервер после изменения `.env`

2. **Для production (PHP прокси):**
   - Вариант 1: Создайте файл `telegram-config.php` в папке `public/`:
     ```php
     <?php
     return [
         'BOT_TOKEN' => 'your_bot_token_here',
     ];
     ```
   - Вариант 2: Установите переменную окружения на сервере:
     ```bash
     export TELEGRAM_BOT_TOKEN=your_bot_token_here
     ```

3. **Для Node.js прокси:**
   - Создайте `.env` файл или установите переменную окружения:
     ```bash
     export TELEGRAM_BOT_TOKEN=your_bot_token_here
     ```

⚠️ **ВАЖНО:**
- Файл `.env` уже добавлен в `.gitignore` - он не будет закоммичен в git
- Файл `telegram-config.php` также добавлен в `.gitignore`
- Не коммитьте секретные данные в репозиторий!

## Устранение неполадок

### Ошибка "CORS"
- Убедитесь, что `USE_PROXY = true`
- Проверьте, что прокси-файл доступен на сервере
- Проверьте права доступа к файлу на сервере

### Ошибка "404 Not Found"
- Проверьте путь к `telegram-proxy.php`
- Убедитесь, что файл загружен на сервер
- Проверьте, что файл находится в корне сайта

### Ошибка "500 Internal Server Error"
- Проверьте логи PHP на сервере
- Убедитесь, что PHP включен и работает
- Проверьте, что функция `curl` доступна в PHP

### Сообщения не приходят в Telegram
- Проверьте токен бота
- Проверьте chat_id
- Убедитесь, что бот добавлен в группу/канал
- Проверьте, что бот имеет права на отправку сообщений
